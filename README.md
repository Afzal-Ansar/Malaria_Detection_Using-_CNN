🧠 CNN on Real-World Images (Image Classification)
Made by: Afzal Ansari

This project showcases the implementation of a Convolutional Neural Network (CNN) for image classification using real-world image data.

🚀 Features
📁 Load and preprocess real image datasets

🧠 Build and train a CNN from scratch using Keras

📊 Visualize training performance (accuracy/loss curves)

🖼️ Evaluate on test images to see model predictions

✅ Hands-on demo for deep learning beginners

🛠️ Tech Stack
Python

TensorFlow / Keras

NumPy, Matplotlib

Jupyter Notebook
